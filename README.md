# Посмотри в окно
## Описание проекта
Перед вами проектная работа второга спринта учебного курса от Яндекс Практикума.
Главное отличие данной Проектной Работы от предидущей в том что работу нужно вести уже над начатым проектом и разбираться в чужом коде
## Используемые технологии
В проектной работе пользовался возможностями CSS для размещения и стилизации уже размеченых на странице элементов чтобы те соответствовали предоставленому макету. Особое внимание уделялось созданию форм, их доступности и стилизации.
