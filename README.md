# Посмотри в окно
## Описание проекта

Перед вами проектная работа второго спринта учебного курса от Яндекс Практикума.
Главное отличие данной проектной работы от предыдущей заключается в том, что работу нужно вести уже над начатым проектом и разбираться в чужом коде.

## Используемые технологии

В проектной работе использовались возможности CSS для размещения и стилизации уже размеченных на странице элементов, чтобы они соответствовали предоставленному макету.

Особое внимание уделялось созданию форм, их доступности и стилизации.
